Tic：清单与待办

iPhone 任务清单 App 的支持页面。

使用与常见问题

  • 在 Lists 中创建清单、分组和任务；Todos 返回最近打开的清单。
  • Calendar 展示设置了日期的待办任务，不会读取或写入系统日历。
  • 到期提醒需要系统通知权限。若之前拒绝，请在 iPhone 的“设置 → 通知 → Tic”中调整。通知预览可能显示任务文字。
  • iCloud 同步使用系统 Apple 账号的私有 CloudKit 数据库。未登录 iCloud、网络不可用或云服务出错时，同步可能不可用或延迟；它不是即时推送同步服务。
  • 照片附件通过系统照片选择器选择。请仅添加你有权使用的内容。
  • 删除已同步的清单或任务会传播至其他同步设备。请勿把同步当成独立的历史备份。

反馈问题

请通过 Tic 支持工单反馈。可提供 App 版本、iOS 版本、复现步骤及脱敏截图。GitHub 工单是公开的：请勿提交密码、Apple 验证码、个人任务、照片或其他敏感信息。提交工单需要 GitHub 账号；使用 App 本身不需要 GitHub 账号。
