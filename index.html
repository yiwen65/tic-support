Tic：清单与待办

iPhone 与原生 Mac App Store 版本的支持页面。各平台是否已可下载，以对应商店的实际状态为准。

iPhone 使用与常见问题

  • 在 Lists 中创建清单、分组和任务；Todos 返回最近打开的清单。
  • Calendar 展示设置了日期的待办任务，不会读取或写入系统日历。
  • 到期提醒需要系统通知权限。若之前拒绝，请在 iPhone 的“设置 → 通知 → Tic”中调整。通知预览可能显示任务文字。
  • iCloud 同步使用系统 Apple 账号的私有 CloudKit 数据库。未登录 iCloud、网络不可用或云服务出错时，同步可能不可用或延迟；它不是即时推送同步服务。
  • 照片附件通过系统照片选择器选择。请仅添加你有权使用的内容。
  • 删除已同步的清单或任务会传播至其他同步设备。请勿把同步当成独立的历史备份。

Mac 使用与数据迁移

  • 使用菜单栏图标中的 New List 和 Search Lists 管理桌面清单。清单窗口可调整颜色、置顶或卷起；Settings 可配置或关闭全局搜索快捷键。
  • App Store 版首启可选择旧 Tic 数据目录导入快照，或明确选择 Start Fresh。导入会读取数据库及已提交的 WAL 内容，不替换原始数据库；后续在旧版进行的修改不会自动进入该快照。本机偏好、快捷键、同步/MCP/登录开关及凭证不在导入范围内。
  • 若要迁移，请在首次设置时选择导入并保留原数据。选择 Start Fresh 后不会再次自动导入或覆盖新库；如需协助，请联系支持，不要先删除旧数据。
  • iCloud 同步在 Mac 上为可选功能，从菜单手动开启。系统账号、网络或 Apple 云服务异常可能导致同步不可用或延迟。
  • MCP 默认关闭，仅应向你信任的本机客户端开放。开启后，客户端可以读取及修改任务等内容，外部工具也可能根据自身设置将内容发给 AI/服务提供方。本 App 使用本机私有 Unix socket，不提供公开 TCP 服务；极端过长的主目录/临时路径会显示不支持的路径错误。
  • App Store 版本通过 App Store 更新，不使用直接下载版的 GitHub 自更新安装器。Launch at Login 受系统许可与设置约束。

反馈问题

请通过 Tic 支持工单反馈。可提供 App 版本、iOS 版本、复现步骤及脱敏截图。GitHub 工单是公开的：请勿提交密码、Apple 验证码、个人任务、照片或其他敏感信息。提交工单需要 GitHub 账号；使用 App 本身不需要 GitHub 账号。
